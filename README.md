# Intelligence Bug Diagnosis Platform with Fix Recommendation Assistance

## Project Overview

The Intelligence Bug Diagnosis Platform is an AI-based software defect analysis system designed to analyze bug reports, error logs, and stack traces.

The platform uses Retrieval-Augmented Generation (RAG), semantic similarity, historical defect knowledge, and specialized AI agents to help identify possible root causes and recommend potential fixes.

## Main Objectives

- Analyze submitted software defects.
- Process error messages, logs, and stack traces.
- Find similar historical defects.
- Identify possible root causes.
- Provide fix recommendations.
- Organize the analysis into a structured diagnosis.

## AI Agents

The system includes:

1. Triage Agent
2. Log Analysis Agent
3. Duplicate Detection Agent
4. Root Cause Agent
5. Remediation Agent

## System Flow
